    MkDocs Library

    Welcome to MkDocs Library, a website automatically generated from Markdown files!

    This site organizes content into sections such as Books and Articles, and is powered by MkDocs with the Material theme.

    Project Structure

    project_folder/
├─ docs/
│  ├─ index.md                  ← your README / home page
│  ├─ books/
│  │  └─ isekai-mokushiroku-mainogura/
│  │     └─ volume-1/
│  │        ├─ chapter1.md
│  │        └─ chapter2.md
│  └─ articles/
│     ├─ article1.md
│     └─ article2.md
├─ css/
│  └─ custom.css                ← optional custom CSS
├─ generate.py                  ← Python script to auto-generate mkdocs.yml
├─ mkdocs.yml                   ← auto-generated by Python script
````

- **Books/**: Nested folders for each book and volume  
- **Articles/**: Markdown articles  
- **css/custom.css**: optional styling  
- **generate.py**: auto-generates `mkdocs.yml`  
- **mkdocs.yml**: automatically generated navigation and theme configuration

## How to Setup Locally

### 1. Install Python (3.8+)

#### Debian / Ubuntu:
```bash
sudo apt update
sudo apt install python3-pip
````

#### Windows:

Download and install Python from [python.org](https://www.python.org/downloads/).

---

### 2. Install MkDocs, Material & Dracula theme

```bash
pip install mkdocs mkdocs-material mkdocs-dracula

    Available themes:

    • material
    • dracula
    • torillic
    • mkdocs
    • readthedocs

    3. Auto-generate mkdocs.yml

    Save the following Python script as generate.py in your project root:

    import os
import yaml

docs_dir = "docs"

def format_title(name):
    # Replace dashes/underscores with spaces and title-case
    return name.replace("-", " ").replace("_", " ").title()

def build_nav(path, base=""):
    nav_items = []
    for item in sorted(os.listdir(path)):
        full_path = os.path.join(path, item)
        rel_path = os.path.join(base, item) if base else item
        if os.path.isdir(full_path):
            children = build_nav(full_path, rel_path)
            if children:
                nav_items.append({format_title(item): children})
        elif item.endswith(".md"):
            nav_items.append({format_title(os.path.splitext(item)[0]): rel_path})
    return nav_items

mkdocs_config = {
    "site_name": "My Library",
    "theme": {"name": "material"},
    "extra_css": ["css/custom.css"],
    "nav": build_nav(docs_dir)
}

with open("mkdocs.yml", "w") as f:
    yaml.dump(mkdocs_config, f, sort_keys=False)

    Run the script to generate or update mkdocs.yml:

    python3 generate.py

    4. Run the website locally

    cd project_folder
mkdocs serve

    Open your browser at http://127.0.0.1:8000 — your website will be live.

    5. Adding new content

    • Place new Markdown files in docs/books/... or docs/articles/...
    • Re-run generate.py to update the navigation automatically
    • Refresh your browser — new pages appear in the table of contents

    6. Optional: Build static site for hosting

    mkdocs build
    • Generates a site/ folder with static HTML files
    • Can be hosted anywhere (GitHub Pages, Netlify, Apache, Nginx, etc.)

    Enjoy your fully modular Markdown library website! 🎉
